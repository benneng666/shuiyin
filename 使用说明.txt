买家秀采集助手 · Windows 桌面测试版
更新：2026-11-09（北京时间）

当前状态
采集范围已扩展为商品主图、详情图、商品视频，以及评价/追评中的图片与视频。
程序提供商品链接识别、平台适配、素材下载与文件校验，并保留每项素材的来源关联。
这不是已通过三平台验收的完整采集产品。
淘宝和抖音适配仍待真实商品页面验收，包括主图、详情图、商品视频和评价追评素材。
小红书商品评价尚未支持；商品资料与评价分别记录，主图/详情图不会被归为买家评价。
图片和视频受平台当前会话可见范围、页面结构和下载地址限制，不保证三平台免登录或抓全。
0.5.0 新增本地图片/视频去水印：自动提出文字水印候选，支持手动画框和视频时间区间，CPU基础修复另存结果。
自动识别不能覆盖所有Logo，复杂纹理可能有修复痕迹，处理前后请预览核对。

启动
集成发行版入口：dist\买家秀采集助手-0.5.11\买家秀采集助手.exe，或双击根目录“启动软件.cmd”。
发行版已包含 Python、图片处理依赖、FFmpeg 视频校验和 Playwright 驱动，无需另外安装 Python；需要本机安装 Edge 或 Chrome。
分发时请保留整个“买家秀采集助手-0.5.11”文件夹及其中的 _internal，不能只复制 EXE。
粘贴商品链接或分享文案（也可导入 TXT），选择保存目录和浏览器，点击“开始采集”。
任务表显示各商品状态、已保存图片数、视频数和下载失败总数。
选中任务查看评价/商品素材记录数量和说明，双击结果行可打开商品文件夹；具体来源见清单。
下载目录、加载上限和浏览器选项会自动记忆；软件同一时间只允许一个桌面实例运行。
运行日志位于 %LOCALAPPDATA%\BuyerShowValidator\logs，已过滤签名参数和认证信息。
默认每个商品最多加载200次，可调到1000次；长详情页需要多次滚动，触及上限仍标为未完成。已有自定义上限会保留。
源码开发模式需 Python 3.11 或更新版本；运行“安装依赖.cmd”后可用“启动验证版.cmd”启动。
遇到登录/验证，请在软件刚打开的独立 Edge 或 Chrome 窗口中手动操作。
确认该独立窗口内已经登录或完成验证，再点软件内“处理完成，继续”。
即使日常 Edge/Chrome 已经登录，也不会共享到软件会话；第一次通常需要在软件窗口重新登录。
点“停止”会保留已保存的记录；关闭软件也会先停止后台任务。
不读取日常浏览器或 Codex 内置浏览器的登录信息。无需把密码发给任何人。
Windows窗口会话保存于 %LOCALAPPDATA%\BuyerShowValidator\profiles。
命令行默认会话保存于当前目录的 .profiles。会话过期后仍需重新登录。

输入范围
只接收商品链接，采集其已适配范围内的商品资料和评价素材。
商品详情中的视频属于本次范围；抖音短视频作品链接、笔记、账号和店铺主页链接不属于输入范围。
已识别直链形式：
  https://item.taobao.com/item.htm?id=商品ID
  https://detail.tmall.com/item.htm?id=商品ID
  https://h5.m.taobao.com/awp/core/detail.htm?id=商品ID
  https://www.xiaohongshu.com/goods-detail/24位商品ID
  https://haohuo.jinritemai.com/ecommerce/trade/detail/index.html?id=商品ID
短链 m.tb.cn、v.douyin.com、xhslink.com、xhslink.cn 先解析，再验证是否同平台商品。
淘宝广告链接 click.simba.taobao.com/cc_im 也先解析到同平台商品页，不能从广告参数猜商品ID。
短链如果跳到视频、笔记或未知页面，会停止并记录原因。
链接识别成功仅代表输入格式可识别，不代表该商品素材可采或包含买家秀。
同批混入错链会给出具体中文错误，请移除后重试。

素材与完成标准
商品主图、详情图、商品视频与评价/追评素材分别保留来源，不将这些类别混为“买家秀”。
评价记录保留商品ID、评价ID、初评/追评类别及已发现图片、视频关联。
抖音实际DOM对追评的表现仍未核验，不承诺已经正确区分其真实追评。
文件必须下载并通过对应文件校验才记成功；HTTP 200的HTML登录页不是图片或视频成功。
保留平台实际提供的图片URL与签名，不删参数猜原图。分辨率写入清单。
同商品相同内容的素材按文件哈希去重，并保留它在商品资料、初评或追评中的关联。
单张图片限制32 MiB；超限、CDN拒绝请求、无法解码都记为失败。
视频单文件限制256 MiB；本版支持已适配CDN上的完整MP4/MOV/WebM/Matroska文件，解码通过才计成功。
blob地址、HLS/DASH播放列表和未适配域名会明确记录为不支持；不会把播放列表或封面当成视频。
视频是否能下载取决于实际地址与当前适配能力；受保护播放流、仅App可见内容不保证取得。
下载不导出浏览器Cookie。若平台保护素材URL，当前下载方式可能失败。
只有适配器确认对应采集范围结束，且已发现素材全部保存，才可能标complete=true。
评价部分需要明确的列表末页依据，不能靠滚动没有变化推断完成。
停滞、加载次数上限、登录、下架、App入口限制、访问失败均不是“抓完”或“没有素材”。
小红书评价未支持时，保存了商品主图也不代表评价完整。
完成口径只涵盖当前会话可见且已适配的范围，不承诺平台隐藏或删除的数据。

输出与恢复
所选下载目录/
  batch-时间.json                  本批每个商品状态与结果位置
  taobao/商品ID/manifest.json      商品素材/评价来源、URL、文件、状态、统计和尝试记录
  taobao/商品ID/images/哈希.png    校验后的图片，扩展名依据真实格式
  视频保存位置                    以 manifest.json 中各视频的文件路径为准
  douyin/...                     同样结构
  xiaohongshu/...                 尚未支持时也保存诊断清单
统计：reviews_read按父评价计数，review_entries把追评单独计入；
image_associations保留图片关联，downloads_succeeded按图片URL计数，unique_images按文件内容哈希计数。
video_urls是已发现的视频URL数，video_downloads_succeeded是视频URL下载成功数，unique_videos是唯一视频文件数。
downloads_failed仍表示图片失败，videos_failed表示视频失败；界面“下载失败”为两者之和。
product_media_count表示商品素材记录数；下载成功数不能代替采集完整性。
任务表中的图片/视频数按该商品累计结果显示，包含已校验复用的文件；批次摘要按任务合计，不代表本次新增文件数。
旧版清单没有视频统计时界面显示0；不把旧清单视为已验证无视频。
没有稳定评价ID时使用合成ID，需要人工核对。
重跑相同商品、相同输出目录，会校验并复用已有素材，重试失败项。
评价列表会从头读取；当前不保存平台分页游标，不支持从上次页码续读。
不同签名URL的相同素材可能重新请求一次，但落盘会去重。
强制结束进程时尚未落盘的记录需重跑；正常停止会尽可能交回已采集快照。

命令行（在本目录 PowerShell 执行）
仅检查链接，不联网：
  .\.venv\Scripts\python.exe -X utf8 -m buyer_show --check "https://item.taobao.com/item.htm?id=878606143823"
批量文件（UTF-8，每行一个商品链接或分享文案）：
  .\.venv\Scripts\python.exe -X utf8 -m buyer_show --file 商品链接.txt --output downloads --max-scrolls 100
浏览器可选 --channel msedge / chrome / chromium；chromium需另装Playwright浏览器。
自动测试，不打开真实浏览器：
  .\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
测试使用合成数据、模拟HTTP与浏览器；通过不等于真实平台可采集。
发行目录的 build-info.json 记录该次构建的依赖与自检信息；以实际运行版本为准。
命令行Ctrl+C会先保存并停止，再次Ctrl+C为强制退出。
依赖实测版本见 requirements-tested.txt。

0.5.0 修复与操作更新
淘宝评价适配新增实页验证的初评/追评图片及视频字段，等待全部评价入口并滚动真实评价抽屉。
不把已读评价文字数量当买家秀下载数；折叠评价或平台访问未完成仍明确报告未完成。
原文件继续保存在images/videos供清单复用；直接使用“素材分类”目录中的独立副本。
素材分类/商品主图/1x1、3x4、其他比例；详情图；商品视频；买家秀/初评或追评/图片或视频。
比例以真实图片显示尺寸判定(2%容差)，不拉伸或裁剪。相同文件多种用途会分别归类，手动编辑副本不会被覆盖。
双击采集结果行直接打开素材分类。去水印自动载入选中任务或最近批次中的成功原件，排除分类副本和processed，避免重复。
去水印支持上一张/下一张按钮、左右键、A/D、PgUp/PgDown切图，Delete删框，Ctrl+Enter处理。编辑数字时这些键保持正常编辑用途。
图片“包含品牌文字候选”可发现更多边角文字，仍需核对；自动OCR默认关闭，避免键盘切图时逐张等待。

0.5.3 商品商家水印优化
默认商家模式，可输入店名/品牌关键词；图片和视频使用相同识别条件。
详情长图分块识别，预览可切100%并滚动，原图与结果同步定位，重新识别保留手工修改框。
图片可选自动背景修补、Telea或NS；视频支持贴边框和较密的分段抽样，仍需检查残留与闪烁。
原始素材和采集清单不被覆盖，操作与实测限制详见“去水印使用说明.txt”。

0.5.4 图片 AI 纹理修复
图片方法新增“AI纹理修复（CPU）”，用于尝试改善复杂背景和分界线处的明显修补痕迹，默认仍为自动。
首次处理下载约208MB模型并核对固定SHA256，缓存后离线使用；启动软件和切换方法不会下载模型。
无需NVIDIA显卡，CPU载入及修复可能等待数十秒，多区域会更久。素材只在本机处理，不上传。
AI可能生成不真实纹理；本次白底和规则条纹样本仍以自动模式更平整。视频仍使用原有区域填补。
去水印对比包与新增素材的实际采集数量单独记录，算法更新不会改变平台登录和素材完整性限制。

0.5.5 长图内存优化
AI前透明背景合成改为分块，减少超长详情图的内存临时数据，输出规则与0.5.4相同。

0.5.6 采集范围与阶段进度
淘宝商品扫描限定当前商品的主图和详情容器，详情动态增长会继续加载，详情结束后不为到达整页底部而滑入推荐区。
找不到详情容器、存在未加载图片/视频或折叠入口时，仍记录部分完成与原因，不能把停止滑动当作全部抓完。
已读取的买家秀先下载并分类，然后读取商品主图、详情和商品视频；这些阶段在任务状态中分别显示。
图片/视频列只统计校验成功的文件；已发现但尚未下载的地址另作进度说明。当前批次已失败的地址不会在下一阶段立刻重复尝试，重新运行该商品仍可重试。
商品739218404250已完成0.5.6正式界面复测：独立空目录取得82张唯一图和1段评价视频，文件哈希及分类集合与0.5.5一致；商品滚动177次降至44次，停在详情边界。
进入商品读取阶段前已保存45张买家秀图片和1段评价视频，整次约69秒；无下载失败。复测时平台另提示3228条折叠评价，当前页面没有可确认的展开控件，仍未取得，任务保持部分完成。

0.5.7 一键去水印
选中任务进入“去水印”，点击“一键去水印”。默认仅处理当前商品主图、详情图和商品视频，买家秀/追评可单独勾选。
软件先分析整批素材；可靠水印自动处理，无候选原样复制，不确定项集中列为待确认，无需逐张点击全部素材。
同一商品中重复、位置稳定且有背景变化证据的品牌文字可获自动批准；相邻署名小字需要同样的跨图布局依据。
智能图片修复按背景选择基础填补或CPU AI，整批复用模型。视频依据有限抽样处理固定商家文字，原音轨保留。
结果目录中“完整素材”继续按商品、主图比例、详情图、商品视频和所选买家秀分类，原件不覆盖。
可筛选待确认/失败并用左右键快速切换精修。取消保留已完成结果和汇总清单。
未检出不等于没有水印；图形Logo、中央淡字、移动/短暂视频水印仍可能漏检，修复也可能留下痕迹。

0.5.8 图形线条与浅色文字补查
自动检查商家文字旁的重复图形与细线，跨原图核对后按小选区处理；另对已知店名增加局部对比度增强识别。
详情信息卡的独立店名可按同商品商家证据处理，参数、说明及与正文混排的不确定文字仍保留。
原件与旧批次结果保留；新结果记录检测证据，便于核对未识别区域。

0.5.9 视频精修
一键去水印默认按背景使用快速插值或AI关键帧精修，复杂视频CPU可能需要数分钟。可选择快速视频修补优先速度。
精修限制180秒/5400帧/两个局部区域，智能模式超限改用快速方式并说明；每段最多120次AI推理，预算回退会记录。
完整输出核对逐帧时间戳、原音轨包和音画偏移，原件保留；仍可能有局部变形或闪烁。

0.5.10 可靠性与完整性标注（2026-11-09）
本节改动已包含在当前 0.5.10 发行冻包中（2026-11-09 重新构建）；
0.5.9 及更早冻包（构建于 2026-11-04）不含以下修复。
· 直连开关：本机代理端口失效（如系统代理 127.0.0.1:7897 未监听）导致浏览器报
  ERR_PROXY_CONNECTION_FAILED 时，命令行运行前设置环境变量 BUYER_SHOW_DIRECT_CONNECTION=1，
  浏览器与素材下载都会绕过本机代理。默认关闭，不改变正常网络行为。
  示例：set BUYER_SHOW_DIRECT_CONNECTION=1 && .venv\Scripts\python.exe -m buyer_show "商品链接" --output 输出目录
· 页面存活：评价阶段结束后若页面已关闭，会在同一浏览器会话中重开商品页；
  商品素材读取遇到 TargetClosedError 时只重试一次，并在清单里留下 recovered_after 记录。
· 完整性标注：折叠评价若平台只显示条数、没有可确认的展开控件，任务说明与清单记为
  「已保存评价记录 X 条；平台不可达 N 条折叠评价」，并写入 folded_unreachable 字段，不再笼统算作软件漏采。
· 商品详情容器未暴露时，记录 detail_container_unavailable 与详情入口的重试证据，
  明确区分「平台未展露」与「读取失败」，不猜新选择器。
